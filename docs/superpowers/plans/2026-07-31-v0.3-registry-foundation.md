# SYCO23 SETCRAWLER v0.3 Registry Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Use superpowers:test-driven-development for every behavior change and superpowers:verification-before-completion before claiming a task or PR is complete.

**Goal:** Deliver the first bounded v0.3 implementation slice: a validated, immutable, capability-based provider registry that wraps the existing YouTube, SoundCloud, and FTM behavior without changing database schema, queue routing, provider network boundaries, API responses, or publication behavior.

**Architecture:** Introduce pure provider contracts and descriptors under `apps/api/app/services/`. Build one immutable registry from descriptors at application startup. Existing adapters remain the execution implementations and are exposed through compatibility wrappers. Persistence, dual-write, workload queues, descriptor-driven health, and generic scheduling remain separate later PRs.

**Tech Stack:** Python 3.12, FastAPI, Pydantic 2, typing protocols, pytest, PostgreSQL/Redis-backed CI, GitHub Actions.

**Owning design:** `docs/superpowers/specs/2026-07-31-capability-provider-platform-design.md`

**Owning issue:** #19

## Scope boundary

PR 1 may create or modify only registry contracts, registry construction, provider compatibility wrappers, startup validation, and tests.

PR 1 must not:

- add or modify Supabase migrations;
- create `providers`, `provider_items`, or `set_provider_items`;
- change `SetSource`, database constraints, or API response values;
- change Celery queues, dispatch, workers, Compose, or durable-job semantics;
- change provider request behavior, timeouts, rate limits, scraper isolation, or retries;
- enable `authorized_audio`, `creator_upload`, downloads, MinIO, playback, automatic merge, or automatic publication;
- change provider-health or search-profile APIs.

## Contracts produced

```python
class ProviderCapability(StrEnum):
    discovery = "discovery"
    metadata = "metadata"
    embed = "embed"
    authorized_audio = "authorized_audio"
    creator_upload = "creator_upload"
    syndication = "syndication"
    license_evidence = "license_evidence"


class ProviderWorkload(StrEnum):
    provider_api = "provider-api"
    provider_scrape = "provider-scrape"
    process = "process"
    audio = "audio"
```

```python
class ProviderItemPayload(BaseModel):
    provider_key: str
    external_id: str
    canonical_url: AnyHttpUrl
    title: str | None = None
    published_at: datetime | None = None
    duration_seconds: int | None = Field(default=None, ge=0)
    creator_name: str | None = None
    embed_url: AnyHttpUrl | None = None
    artwork_candidates: tuple[AnyHttpUrl, ...] = ()
    raw_metadata: dict[str, JsonValue] = Field(default_factory=dict)
    provenance: dict[str, JsonValue] = Field(default_factory=dict)
    license_evidence: dict[str, JsonValue] | None = None


class DiscoveryRequest(BaseModel):
    operation: str
    parameters: dict[str, JsonValue] = Field(default_factory=dict)
    cursor: str | None = None
    limit: int = Field(default=25, ge=1, le=100)


class DiscoveryPage(BaseModel):
    items: tuple[ProviderItemPayload, ...]
    next_cursor: str | None = None
```

`AuthorizedAudioCandidate` is a reserved typed reference for later releases. It may contain URLs, expected hashes, and rights evidence references, but never bytes or local file paths. No built-in PR 1 descriptor may declare or call `authorized_audio`.

```python
@dataclass(frozen=True, slots=True)
class ProviderDescriptor:
    key: str
    display_name: str
    capabilities: frozenset[ProviderCapability]
    workload_by_capability: Mapping[ProviderCapability, ProviderWorkload]
    adapter_factory: Callable[[], object]
    url_matchers: tuple[Pattern[str], ...]
    required_settings: tuple[str, ...] = ()
    enabled_by_default: bool = True
    descriptor_version: int = 1


class ProviderRegistry:
    @classmethod
    def build(cls, descriptors: Iterable[ProviderDescriptor]) -> "ProviderRegistry": ...
    def get(self, key: str) -> ProviderDescriptor: ...
    def adapter(self, key: str) -> object: ...
    def require_capability(self, key: str, capability: ProviderCapability) -> ProviderDescriptor: ...
    def match_url(self, url: str) -> ProviderDescriptor: ...
    def descriptors(self) -> tuple[ProviderDescriptor, ...]: ...
```

Use existing exception conventions where possible. Registry-specific exceptions may be:

- `ProviderRegistryError`
- `ProviderNotRegisteredError`
- `ProviderCapabilityError`
- `ProviderUrlMatchError`

The full operational error taxonomy remains PR 4 scope.

### Step 1: Write failing descriptor tests

- uppercase, blank, or malformed keys;
- empty display names;
- duplicate matcher patterns;
- a capability without a workload mapping;
- a workload mapping for an undeclared capability;
- `audio` workload for current metadata-only capabilities;
- a capability whose required adapter method is absent;
- a callable capability method exposed by an adapter but omitted from its descriptor;
- `authorized_audio` without both rights decision and authorized fetch methods;
- `creator_upload` without ownership verification and upload acceptance methods;
- required-setting declarations that contain values rather than setting names.

Required method mapping:

| Capability | Required method |
|---|---|
| `discovery` | `discover(request)` |

| `creator_upload` | `verify_creator_ownership(identity, evidence)` and `accept_creator_upload(request)` |
| `syndication` | `syndicate(request)` |
| `license_evidence` | `resolve_license_evidence(reference)` |
